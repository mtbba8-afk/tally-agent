# Demo video script (2:45)

Record the hosted demo. No slides, no music, no third-party logos beyond what the product itself shows. Sandbox only.

**0:00** "Small shops get paid late because the invoice happens at the kitchen table. I'm Mohamed. I sell to these shops in Brooklyn. This is Tally Voice on a real HVAC book."

Show the desk. Outstanding balance is already there.

**0:20** Open Call. Hit **Play the recorded call**. Dana Ruiz, warm air, 418 Bergen Street, tomorrow morning, phone number. The booking card fills in. Say: "Same function if I speak live. The recording is here so the demo does not depend on a microphone."

**0:50** Submit the tech note: replaced capacitor, 1.5 hours. Open the invoice. Point at **Price book** on the capacitor and the labor line. "The model did not pick these prices."

**1:10** Open the owner phone. Hit **Reply YES**. The invoice flips to sent. If sandbox keys are on, show the PayPal payer link. If not, say the mock gateway uses the same send code path.

**1:25** Open the pay page. Read the Pay in 4 line. Pay the balance, or complete the sandbox checkout and run **Check PayPal for payment**. The status becomes paid. Say: "That is the same reconciler the PayPal webhook hits."

**1:50** Open Cash. Sort the aging column. Read who to call today and the 14 day number. Ask the books "Who should I call today?"

**2:10** On a sent invoice, **Simulate a dispute webhook**. The packet quotes the job note and the price book. Approve it. "Nothing goes to PayPal until a person says so. A demo dispute id stays here. A real sandbox id is submitted."

**2:25** "Prices are locked to the book. Sent amounts do not change. The log has every step. PayPal is sandbox. Stack is Next.js, the PayPal Agent Toolkit, webhooks, AG Grid, and a voice path that still works with no model."

**2:40** "If you run a shop and the money shows up late, this is the loop. Link is in the description."

Leave the cash grid on screen as you stop.
